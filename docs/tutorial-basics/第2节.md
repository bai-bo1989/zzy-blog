# 2.stm32cubeide的安装
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Hello,小伙伴们,大家好,这里是左左右,今天我们讲stm32cubeide这款软件的安装，在安装之前先说一下我为什么选择这款软件。  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;1.集成化的开发环境  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;stm32cubeide内置图形化配置工具（STM32CubeMX），支持通过可视化界面配置引脚、时钟、外设等，自动生成初始化代码，极大简化硬件配置流程，学过keil5的同学应该知道，初始化的过程是非常痛苦的，不利于新手的学习，当然，如果大家感兴趣我也会单独推出keil5的课程来供大家学习。  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;2.免费  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;官方提供完整功能，无需付费许可证，适合个人开发者和企业，
STM32CubeIDE 是ST公司
也就是意法半导体推出的官方集成开发环境（IDE）
专为STM32微控制器设计。
学过前面课程的同学应该还记得
stm32这款单片机也是由ST公司推出的  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;3.跨平台  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;同时支持 Windows、Linux 和 macOS  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;4.内置HAL库  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;HAL库相对于标准库有诸多优势，比如可跨芯片系列移植代码
HAL库由官方持续更新，而标准库已停止更新  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;好了，下面讲一下这款软件是怎么安装的吧。
首先我们打开搜索引擎，输入stm32cubeide官网，找到带有意法半导体字样的网址，找到Windows版本点击下载，但是国内连接ST官网下载速度很慢，由于要录这期视频，我就把之前的CubeIDE这款软件卸载了，结果昨天晚上下载一晚上都失败了，直接导致我这期视频晚出了一天，为了避免大家在单片机学习道路的第一关就被却退了，我讲网盘链接放到了我的个人公众号了，请大家自行下载
下面，我们将下载好的安装包解压，双击打开安装程序，跟着我的视频一步一步点击就可以了，这里我建议将软件的安装位置不要放到C盘，下面我们双击打开程序，这里是我们将来程序的存放位置，也不建议放到C盘，同时要注意安装路径和程序的存放路径中都不能有中文，好的，到这里我们的软件就安装好。  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;好的，今天的课程就到这里了，大家点点关注，你们的一键三连是我更新下去的最大动力。

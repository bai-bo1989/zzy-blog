# 1.初识stm32
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Hello，小伙伴们，大家好，这里是左左右，今天给大家带了一整套stm32入门加实战的教程，首先这一节我们要知道什么是单片机？，单片机其实就是一种集成电路芯片！它就像是一个微型的计算机系统，把中央处理器CPU，随机存储器RAM，只读存储器ROM，还有好多I/O口，中断系统，定时器/计数器等功能，都集成到了一块小小的硅片上，从而构成的一个小而完善的微型计算机系统也就是我们俗称的MCU，单片机可以说是麻雀虽小五脏俱全，这些 名词对于刚接触单片机的小伙伴们可能有些陌生，在后面的课程中我会为大家一一讲解，单片机的应用场景随处可见，就像在我们家用电器里，比如冰箱、电视、洗衣机，都有单片机的身影，它控制着电器的运行，让我们的生活变得更加方便，在工业控制领域，单片机也是大显身手，比如PLC控制系统、传感器数据采集系统，都离不开它，还有汽车电子里，像发动机控制、车窗控制、安全气囊，也都是单片机在发挥着作用，让我们的出行更加安全舒适。，另外，在医疗设备、通信设备、智能设备、智能家居，无人机等领域的应用也十分广泛。，接下来说一下我们后面课程要讲的这款芯片，stm32f103c8t6，它是由ST公司也就是意法半导体推出的STM32系列芯片之一，那么stm32f103c8t6这一长串数字加字母代表什么呢，其中ST代表的就是ST公司，M代表MCU，32代表的是基于ARM核心的32位微控制器，F代表通用类型，103代表增强型，C代表引脚数为48，8代表闪存容量为64k，T代表封装形式为LQFP，6代表适用温度为-40℃~85℃，关于这些知识，大家有一定的了解就可以了。，目前大多数的教程都是以入门为主，没有配套的实战项目，而很多的开源的单片机项目呢，由于难易程度的不同，导致很多只学了入门的同学很难上手，所以我精心为大家准备了这个
